## 📖 Overview

Phantom Binary is an autonomous binary radar and reverse-engineering controller. It detects software updates, extracts selected executables, runs full or lightweight Ghidra analysis, supervises analysis processes, and reports results through Discord.

---

## 🚀 Status

**Production**

Phantom Binary is part of the active single-VPS Docker Compose deployment.

---

## 🎯 Responsibilities

- Software update monitoring
- Selective archive extraction
- Headless Ghidra analysis
- Discord command control
- Java process supervision
- Direct report delivery
